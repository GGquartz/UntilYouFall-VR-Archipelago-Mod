## Project AI usage disclosure

**TL;DR: Not vibecoded, AI is being used under thorough review**

Agentic coding was used to write parts of this project, specifically Codex CLI with Claude and Codex, using relevant skills and plugins. This project is **not** vibecoded. I've been efficiently using AI at work for the past year or so and I feel confident enough to say that I know what I'm doing.


All code is **thoroughly** reviewed. All apworld logic is and always will be set by me. Since this is my first AP implementation, conversations were used to discuss how AP works and how other worlds do stuff, but I come up with all the design/structure/feature ideas and decisions, this will never change and AI will never make the big decisions. The biggest use is for stuff like diagnostics and research, saving time instead of combing through the game manually using dnSpyEx or UnityExplorer... It is also used for creating helper tools, workflows and writing tedious code like setting and manipulating in-game objects and making sure all values and parameters are set correctly. Agents also help with code review and help me find issues so that I might consider refactors. Almost all of the tests are written by AI, they are there just because sometimes they help catch a mistake I made, the tests are not reviewed as much because they are just there as an extra safeguard on top. AI is very helpful with proper logging systems and analyzing log files and finding causes of problems. Logs will never contain sensitive information.


**Everything is playtested extensively**, before the 0.1 release I've already gone through multiple full playthroughs, even real-time syncs. This does not mean the mod will work perfectly, bugs and crashes are expected in alpha releases.

Documentation will never be written by AI. Responses to questions about the project will never be AI generated. No assets or art will ever be created by AI.


I feel confident about the quality of the code and functionality, without AI usage this project would probably take months longer, usage of the workflows above will continue.
